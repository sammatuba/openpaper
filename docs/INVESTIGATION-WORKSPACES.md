# Investigation workspaces

Open a project and use Case, Evidence and Draft. Existing project papers,
discussions and the optional research brief remain available in the same shell.

1. In Case, enter the question, provisional answer, unresolved tension and proposed
   discriminating experiment. Add claims and record caveats. Start from existing
   brief explicitly copies the imported brief (or legacy description) into unsaved question/context/provisional answer fields; it does not
   manufacture findings or overwrite the original brief.
2. In Evidence, choose a project paper and inspect exact extracted-text lines.
   Attach the displayed quotation, then distinguish observed results, authors’
   interpretation and your own inference. Record setup and limitations separately.
   Relate findings to claims as supports, challenges or qualifies. Select findings
   for comparison; different tasks or controls can motivate a candidate explanation
   without establishing a contradiction or causal result.
3. In Draft, explicitly create sections. Select claims/findings before preparing
   a manual paragraph or a verified source quotation. Review and insert explicitly;
   Cancel leaves the draft unchanged. Gap blocks state missing evidence. Proposed
   experiments remain proposals until real results are supplied.
4. Save investigation persists the entire case/evidence/manuscript together. Saved,
   Unsaved changes, Saving, Conflict and Save failed show its state. A stale save
   keeps local work. Cancel a reload to retain it; download an unsaved recovery
   bundle before discarding. Switching these project views keeps unsaved edits.
5. Click a paragraph’s finding label to inspect its quotation, then Open PDF source.
   Close reader returns focus to the source button. Extracted lines are verified;
   PDF page mapping is explicitly unknown and text search may fail.

A paragraph retains the evidence pins from insertion. Source changes, revised
interpretations/setups/relationships or archived dependencies require review;
ordinary Save never clears that warning. Existing source-quotation blocks keep their original insertion snapshot through a finding rebind. Rebind the finding to inspected current
lines, then explicitly acknowledge the paragraph after review. Unavailable sources
are redacted on subsequent reads/exports. Authored prose remains your work.

## Assistant drafting

Manual drafting requires no model credits. Draft with assistant opens the review
without a model call. Save current work, choose a configured provider and selected
current findings, then press Generate paragraph to make one model request.
Existing chat credits and saved discussion messages account for the action.
Only bounded current project evidence and case/selected claims are sent.

A generated paragraph is a proposal until you explicitly insert it. Valid finding
markers become traceable references; unmarked sentences remain uncited. A
validated marker does not establish factual correctness. AI authorship remains
visible after human editing. A workspace/evidence/section change requires renewed
review and cannot silently overwrite the manuscript. Discard leaves it unchanged.

Interrupted or timed-out requests keep their identity. Check request status to
recover a completed result. The server never automatically repeats a claimed
request. Failed or uncertain requests may have contacted the provider; a new
Generate action is a new explicit request. Manual work remains available.

## Reader and portability

Open folded preview uses the native upstream Textfold engine and five levels.
Keyboard1–5, wheel/pinch zoom, local unfolding and the Topic map operate inside
that reader. Input fields retain their keyboard behavior. Theme changes preserve
the editor and reader instance. Local excerpts and AI-provided content keep their
provenance. Reader preferences/annotations are local to the user/project/version;
Export local reader annotations is explicit and never shares them automatically.

Saved bundle, Markdown and BibTeX exports recheck source access. Markdown marks
uncited, stale and AI-authored prose; BibTeX uses only known bibliography and
requires publication review. Unsaved offline recovery retains authored work but
omits captured source quotations/bibliography, replacing them with unbound
locators. Preview imported bundle remaps IDs and treats all imported citations as
untrusted. Confirm creates an unsaved document; explicitly bind current project
source lines before citing. Imported content cannot authorize assistant requests.

Owner/admin/editor roles can edit; viewers can inspect and export. Existing
admin-only legacy brief/settings rules remain unchanged. All edits and model
request actions recheck project access on the server.
